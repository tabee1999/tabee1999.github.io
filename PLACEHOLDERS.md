# Placeholders to fill in

Your resume is already in: experience, skills, education, impact numbers, contact details and the downloadable CV. What's left is below. Everything lives in `content.js` unless noted.

Unfinished items are hidden on the public site, so it looks complete even now. Run `npm run draft` to see them highlighted, and `npm run placeholders` for the exact list.

## Before you share the link

- [ ] `site.url`: your live address, e.g. `https://your-username.github.io/portfolio`
- [ ] `site.repoUrl` and `person.github`: your GitHub profile and the repo for this site
- [ ] `site.formEndpoint`: your Formspree form endpoint

## Highest impact for hiring managers

- [ ] `caseStudies` (×3): the facts are filled in from your resume. Add the **why** behind each decision, team size, what was slow or risky before, what changed for the team, and what you'd do differently.
- [ ] `projects`: real repo names and URLs, a one-line purpose, what each repo actually demonstrates, and links to published test reports. If your work code is private, build two small public repos (RestAssured API suite, Playwright UI suite).
- [ ] `snippet`: replace the example with a real snippet from one of your repos

## Supporting proof

- [ ] `workSamples` (×4): which public app each sample covers, and a link to the PDF, Notion page or Google Sheet
- [ ] `testimonials`: two short quotes (LinkedIn recommendations work well). Hidden while empty.
- [ ] `certifications`: add any you have. Hidden while empty.

## Optional

- [ ] `person.photo`: a square photo in `public/images/`
- [ ] `writing`: articles or LinkedIn posts (hidden while empty)
- [ ] `site.plausibleDomain`: turns on privacy-friendly analytics
